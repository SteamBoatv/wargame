## 关键决定

- 工程师时代 III 正式采用 CraftPix 绿色坦克；AI v5 不再作为主方案，因为成熟多动作素材的速度、稳定性和一致性更高。
- 坦克定位为短射程喷射、缓慢推进、笨重结实的自动近战英雄，当前没有专门反制角色。
- 生产条必须先到 100%，之后才开始 2.8 秒空投和 2.0 秒启动；不把演出时间塞回生产时间。
- 不实现玩家选择、移动或攻击指令；用户明确纠正过“演出期间可提前下命令”不符合本游戏完全自动化。
- 自修只在战斗结束、准备继续推进前触发；单次最多 10%，完整恢复故意拉长，不采用 2.5 秒快速回血。
- 维修时重新接敌不瞬间跳帧，完成当前循环并收拢；已恢复生命保留，未完成额度作废。
- 全局生产完成提示延期；本轮只做单位附近的空投、尘土、维修加号等程序化占位。
- 所有后续素材缺口、设计思路和验收结论统一写入 `docs/ERA3_ASSET_AND_DESIGN_TODO.md`。
- 镜头安全区按 HUD 实际布局动态计算，不写死生产栏高度；地图额外可视余量不改变模拟坐标。
- QA 页面只临时从本机暴露；云服务器利用公网 IP 和 HTTPS 入口，但不保存 HTML、图片、游戏资产或预览状态。
- 对局遥测继续存云服务器，与临时 QA 预览分离；清理 `/qa/` 不得删除 `/t/` 数据。
- 项目重复工作只做项目级 skill，位置为 `D:\wargame\.agents\skills`，不要安装为个人全局 skill。
